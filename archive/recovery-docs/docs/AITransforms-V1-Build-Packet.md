# AITransforms V1 Build Packet

## Project Mission

AITransforms is a technical AI transformation studio helping businesses turn their business brain — knowledge, documents, workflows, frameworks, and decisions — into practical AI systems.

Core message:

Business Brain → AI Systems

Display name: Hiwa  
Role: AI Transformation Architect & Founder, AITransforms

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS

- Static routes

- `/` English, LTR
- `/fa` Persian/Farsi, RTL

## Design Direction V1

Light-first, professional, technical, founder-led, minimal but credible.

Avoid:

- cyberpunk/neon AI visuals
- fake enterprise style
- generic AI SaaS look
- dark-mode-first design
- robot imagery
- fake clients, testimonials, metrics, or logos

## Phase 2 Design Direction

Editorial studio with technical restraint.

Make the site feel warmer, sharper, more distinctive, and less like a simple mockup while preserving clarity, performance, RTL support, and static deployment.

## Phase 2 Content Decisions

- Use founder display name: Hiwa
- Use role: AI Transformation Architect & Founder, AITransforms
- Replace fake/non-linked resources cards with an honest “resources coming soon” teaser
- Keep CTA as email/contact unless a real booking link is provided

## Do Not Build

- CMS
- database
- authentication
- blog engine
- complex backend
- AI CEO Assistant backend/demo
- heavy i18n library
- heavy animation library
- fake proof
