# Wins From Inside AI Operator Academy

The Sprint you're running here is the free version of what members run inside **[AI Operator Academy](http://;ahttps://www.skool.com/aioperatoracademy/about)**. This page is where I share what happens when operators run the full system.

They came from running a boring, repeatable system with support: list, outreach, follow-up, assessment, and retainer. It is the same loop you're learning in the Sprint, with the full playbook behind it.
