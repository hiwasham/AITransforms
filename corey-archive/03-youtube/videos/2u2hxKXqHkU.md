Key Points

OpenClaw installs with a single terminal command — the only prerequisite is having Node.js installed first, which is also a one-command setup.

The guided onboarding walks you through every decision (model choice, API key, channel, search provider) so you don't need to touch config files manually.

Creating a Telegram bot takes about 60 seconds: message BotFather, run /newbot, pick a name ending in "bot," and copy the token.

DuckDuckGo is the easiest search provider to start with because it requires zero additional setup or API keys.

Skills and hooks can be configured after the initial setup — you don't need to figure everything out before getting your agent running.

Section Summaries

1. Installation and Onboarding
I run the OpenClaw installer from the terminal and walk through the guided setup — choosing Anthropic as the model provider, entering my API key, and selecting Claude Sonnet 4.6. The whole onboarding is a series of simple prompts, no manual configuration needed.

2. Telegram Bot Creation
I open Telegram, message BotFather, and create a new bot in about 60 seconds. The process is straightforward: pick a name, choose a username ending in "bot," copy the token, and paste it into the OpenClaw setup.

3. Testing and Pairing
Once the setup completes, I test the bot in the OpenClaw browser control panel, then pair it with Telegram using a simple terminal command. Within seconds, the bot responds to messages directly in Telegram — fully functional and ready for customization.
