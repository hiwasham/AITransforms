Key Points

• Skills beat Claude projects on token efficiency because Claude reads the skill's table of contents and only loads the file it needs, instead of dumping every project doc into the context window on every message.

• Tom's voice profile auto-rebuilds weekly via a script that pulls his last seven days of X posts through the X API, ranks them by engagement, and rewrites the profile based on what's actually performing.

• The /insights command in Claude Code is a hidden native feature that analyzes all your past sessions, surfaces the patterns and rule violations Claude is making, and outputs copy-paste prompts to upgrade your CLAUDE.md and build new skills.

• Run /insights weekly — it tells you which prompts you keep retyping and converts them into skills automatically, plus generates prescriptions for autonomous content pipelines based on your actual friction points.

• Whisperflow doesn't just transcribe faster than typing — it forces you to think more clearly in real time, because rambling shows up in the transcript and you learn to be concise at the source.
