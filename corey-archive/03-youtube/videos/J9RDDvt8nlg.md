## Description

I sit down with Leon van Zyl, who ran a web design company for 10 years and now teaches over 700 people how to build real applications with coding agents. Key Points

You don't need coding or design skills — just a Google account for Stitch and a coding agent like Claude Code or Cursor.

Going straight into a coding agent without a design system wastes hours and credits. Front-load the design in Stitch first.

Stitch generates a complete design system (typography, colors, spacing) stored in a design.md file that your agent follows for every future page.

Share Stitch mockups with clients before writing code to lock in approval early — pro web design workflow, just 10x faster.

One line in your agents.md file forces your agent to follow the design system consistently across the entire project.

Converting images to WebP and storing them locally dramatically improves page load speed and reduces bandwidth costs.

Section Summaries
