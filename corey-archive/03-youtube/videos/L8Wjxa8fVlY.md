Summaries

1. The Tool Stack That Actually Matters

Ryan tested hundreds of AI tools and concluded 95% are white-labeled wrappers. His daily stack: Claude Code for copywriting, research, and business tasks. Google Gemini Pro ($20/month) for Imagen 3 image generation plus Gmail and Drive integration. Make.com for automations. Simple beats complex when you're trying to get work done.

2. Claude Code Setup: Skills and File Management

Ryan organizes Claude Code into folders: skills, system skills, and assets. Skills are markdown files with specialized knowledge Claude invokes just-in-time. System skills handle meta-tasks like creating new skills and troubleshooting. His thumbnail skill folder contains headshots, logos, and examples he can reference by filename. The skill updates based on feedback—learning which assets perform better over time.

3. Problem-First Mindset

The wrong questions: "Should I use Claude Code or N8N?" The right question: "What's eating 5-10 hours of my time every week?" Start with the problem, work backwards to the tool. Problem-first thinking separates people who get results from people who collect subscriptions..
