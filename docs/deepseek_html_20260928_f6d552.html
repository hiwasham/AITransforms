Section 02

Autonomy & approval

Reversible work proceeds. Irreversible or customer-visible actions wait for an explicit gate.

PROCEED No approval needed

  • Research and analysis
  • Connected-data reads
  • Drafts and internal files
  • Recommendations
  • Any other reversible work

GATE Explicit approval first

  • Sending email, Slack, or customer messages
  • Publishing or scheduling public content
  • Changing a live website or production config
  • Creating, activating, or changing ad spend
  • Destructive, irreversible, legal, or customer-visible actions
Gate simulator
Draft → Reviewable state → Approval gate → Publish
Without an explicit, current approval, the agent stops at a reversible state — a draft, a paused campaign, a preview branch — and names the precise blocker.
