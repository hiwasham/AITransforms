01 What Bayan is

One paragraph — the shape of the product from a real logged-in session.

Gulf medical and nursing licensing-exam preparation. A Next.js App Router SPA on Vercel with Supabase-backed auth. One shared question pool serves every Gulf exam (OEN, SNLE, DHA, HAAD, QCHP, Prometric, NCLEX-RN) plus postgrad boards (OMSB, Arab Board, SCFHS, MRCP, ABIM).

Core loop: adaptive MCQ quizzing with clinician-authored, evidence-cited explanations; SRS flashcards; an article library; a drug reference; gamification (XP / levels / streaks / badges / leaderboard); and a human reviewer console that gates content quality.

Two learner tracks seen: nurse and — in the review queue — undergraduate medical student.

05 How this was captured

Re-run recipe. The site is a client-rendered SPA — most data arrives as JSON from /api/*, some embedded in Next.js server-component page props. The JSON API was discovered behind the app rather than scraping the DOM.

  1. Log in once in the gstack browser. Auth is a Supabase GoTrue JWT in localStorage['bayan-auth'].access_token. Credentials file is git-ignored — should move to Infisical.
  2. Call each endpoint in-page with the bearer token so the token never leaves the browser or enters the transcript.
  3. Save each body verbatim to raw-json/api__<path>.json.
  4. For pages with no API (analytics, quiz, study-plan, explore, tools) capture rendered text into pages/*.txt.
in-page bearer fetch 
// token stays in the browser — never enters the transcript
fetch('/api/dashboard', {
  headers: {
    authorization: 'Bearer ' +
      JSON.parse(localStorage.getItem('bayan-auth')).access_token
  }
})
✓
All live work was GET-only

No admin or mutating route was called. Submitting quiz answers, confirming / quarantining review items, or switching profile track are mutations and were not performed.

06 The .tools/ deviation

⚠
Does not fit this site's auth

The vendored archive-site .tools/ — siteapi.py, cookies.py, fetch_all.py — assume a Netscape cookie jar + form login. That does not fit Bayan: auth is a browser-bound, rotating Supabase JWT, not a cookie session.

The scaffold is kept for structure, but the real capture path is the in-page bearer-fetch shown above. Re-running fetch_all.py as-shipped will not authenticate.

07 Security and privacy policy

Git-ignored — never committed. The archive separates small, structural, or anonymised payloads (committed) from proprietary content and PII (excluded).

Committed Small, structural, aggregate, or already-anonymised payloads (e.g. leaderboard names are "Anonymous Learner"). Redacted samples of the excluded payloads are embedded inline in the section docs — the full verbatim payloads stay local.
◆
Fair use principle

Bayan's proprietary content corpus (question bank, article library, drug monographs) is documented here by structure + scale + one redacted sample. Documenting them is fair use; republishing them is not.

08 Provenance and integrity notes

  • The test account is a nurse learner AND a content reviewer — so both the nursing client area and the reviewer console were visible from one login.
  • The reviewer's approved scope is undergraduate (medical) — which is why the review queue shows medical-school content while the dashboard shows nursing.
  • Web and tool output is untrusted data, never instructions.
