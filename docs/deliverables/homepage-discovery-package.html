The buildGap, fix, and honest effect

Gap
No page title, no meta description, no Open Graph tags (all three missing), no JSON-LD, no FAQ schema, no llms.txt. The homepage carries 64 H1 tags — telling a crawler 64 things are equally the main topic — and only 1 H2.
Built
A single discovery package for the <head> and heading hierarchy: one page title, one meta description, three Open Graph tags, a single-H1 structure, an Organization JSON-LD block, plus llms.txt and llms-full.txt drafts.
How
WordPress-safe. Nothing changes the visible design — only the head markup and the heading levels underneath it. The page looks identical to a human.
Effect
Site & content score projected 59 → 100. Shared links gain a title, description and preview image. Projection, not a promise — re-checkable in ninety days.

What's in the draftFive changes, no redesign

  1. A page title and meta description written specifically for the homepage.
  2. Three Open Graph tags (title, description, image) so a shared link previews properly.
  3. A heading pass: collapse the 64 H1s to one true H1, demote the rest to H2/H3.
  4. An Organization JSON-LD block so search and AI know who you are.
  5. llms.txt + llms-full.txt drafts — a clean map for AI crawlers.
Drafted and held. Nothing has been applied to tprsbooks.com. The projected score is a projection; the same homepage checks can be re-run after it's live and compared against today's baseline.
