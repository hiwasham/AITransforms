# Level 3: AI-Focused Blog Post Creation Guide

**Guide Name:** AI-Focused Blog Post Creation
**Within Blueprint:** Inbound Content Strategy
**Owner:** Hiwa
**Audience:** Whoever writes a post (founder, freelancer, future hire)
**Est. Time:** 3-4 hours per post

---

## When to Use This

You have an approved topic from the content calendar and need to produce a publish-ready English draft (FA/AR handled downstream).

## Before You Start

- [ ] Topic approved from content calendar
- [ ] Target keyword chosen
- [ ] Specific customer pain point identified

---

## Steps

### 1. Research (30 min)
- Read the top 5 ranking articles for the target keyword
- Note gaps and weak points you can beat
- Collect 2-3 real customer quotes/questions on the topic

### 2. Outline (20 min)
- Problem statement → Framework/solution → Implementation steps → Example → CTA
- One specific next step for the reader at the end

### 3. First Draft (90 min)
- Write straight through, no editing
- Short paragraphs (2-3 sentences), subhead every 200-300 words
- Add code/diagram placeholders where needed

### 4. Technical Review (20 min)
- Verify every technical claim; test any code
- Check framework terms match the Empower curriculum

### 5. SEO Optimization (15 min)
- Keyword in H1, first paragraph, one H2
- Meta description (150-160 chars)
- 2-3 internal links, 1-2 authoritative external links
- Image alt text

### 6. Multi-Language Prep (15 min)
- Mark culturally-specific sections for adaptation
- List technical terms to keep in English

### 7. Final Polish (20 min)
- Read aloud for flow; cut to <2000 words
- Strong hook, strong CTA, proofread

### 8. Publication Handoff (10 min)
- Hand EN draft + adaptation notes to Multi-Language step
- Mark status in content calendar

---

## Quality Checkpoints

- [ ] Solves a specific customer problem
- [ ] Technical accuracy verified
- [ ] SEO checklist complete
- [ ] Adaptation notes written for FA/AR
- [ ] CTA is one clear action

## Common Problems → Fixes

- Too technical → add "what this means for your business" lines
- Too long → cut background, keep actionable steps
- Weak hook → open with a customer pain quote or surprising stat
- Unclear CTA → end with exactly one next step

## When Finished

- Add permalink to content inventory
- Watch traffic/engagement first 48h
- Note high-engagement topics for future deep-dives
