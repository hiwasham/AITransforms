## How the levels connect

Strategy flows **down**: the Core Process sets the goal (10-20 qualified
leads/mo) → the Blueprint turns the Attract/Engage stages into a weekly content
workflow → the Guide gives step-by-step execution → the Template is the actual
tool a writer fills in.

Quality flows **up**: the Template guarantees consistent output → the Guide
guarantees consistent process → the Blueprint guarantees consistent coordination
→ the Core Process guarantees consistent business results.
