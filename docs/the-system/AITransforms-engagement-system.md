## 1. The thesis (the one line every engagement serves)

> Convert an existing, high-trust founder relationship into a defined, revenue-owning
> marketing/AI role — by proving, in the first weeks, that anchored content and systems
> turn the founder's *own* base into paying users, then earning the fee raise on traction.

The wedge is never "we make content." It is **"content and systems tied to business goals
and a number."** That reframe is what separates us from the incumbent agency.

## 2. The reproducible play — five phases

### Phase 0 — Pre-work, before first contact
The reason we can move "in days, not months": we **analyze the entire company up front,
before or while they decide.**
- Audit every public surface (site, product pages, app listings, booth, social).
- Build the product/UX QA, SEO + AI-visibility audit, revenue/sales diagnostic.
- Find the **drift problem** (same fact, different value on different surfaces) — it is
  the foot in the door and the source-of-truth wedge.
- Draft in three languages (English default, Persian, Arabic RTL) for Gulf clients.

### Phase 1 — The first email (conversion-first, proof-during-wait)
- **Lead with the delay, not excuses.** Own the lateness, then convert it into output:
  *"we stopped planning and started building."*
- Answer the founder's points **in order**, one by one.
- Face the hard revenue fact honestly (grandfathered users / free countries → the base
  is partly "won't pay" already). Measurement first, not more copy.
- **Near-zero CAC** framing: convert users already in the door; $0 ad spend until the
  funnel proves itself.
- State the fee plainly and the next acceptance point.

### Phase 2 — The single-link plan page
- One self-contained page (HTML) that is **short on the surface, deep one click open.**
- Every item tied to a revenue stage (Lead→Sale, Sale→Delivery) and a number.
- One clean bookmark index for the client (GitHub-hosted), so attachments stop piling
  in email.

### Phase 3 — Fee + task-list follow-up (this email, sent after "go")
- Restate the agreed fee and the exact payable date.
- Give the **concrete task list** for the paid period (weeks), each item measurable,
  each tied to a number.
- No new approvals needed to start — lower the decision surface.
- See `ceo-email-fee-tasks.md` for the standing template.

### Phase 4 — The sprint + the fee ladder
- A **30-day trial, weekly deliverables**, then a go/no-go for months 2-3.
- Week 1: segmentation + funnel analytics + 3 landing pages + checkout test.
- Week 2: onboarding flow + trial-ending sequence + upgrade prompt.
- Week 3: re-engagement drip + single-exam SKU + grandfathering proposal + Instagram cohort.
- Week 4: before/after funnel, revenue added, which lever moved, go/no-go.

## 3. The fee ladder (Bayan as the worked case)

| Rung | Fee | Role |
|------|-----|------|
| Incumbent agency | 145 OMR/mo | content operator (what we must outperform) |
| Plan 1 (anchored) | 250–300 OMR/mo | content operator — CEO's default |
| This month | 400 OMR (500 agreed − 100 travel) | conversion-first sprint |
| Full rate | 500 OMR/mo | marketing role + systems |
| Target | 650–900+ OMR/mo | marketing owner |
| Goal | ~1000 OMR/mo | earned on traction |

Separate product-brain wedge: **$500 pilot → $200/mo retainer** (same engine we use for
every "turn knowledge into working AI systems" job).

The raise rule (founder's own language): **base + 20% deal commission + scale on traction.**
We never ask for the raise; we *deliver output that visibly outperforms the incumbent,
attach it to a funnel metric* — then the ladder climbs itself.

## 4. Standards & red lines (apply to every engagement)

- **Outcomes over vanity** — every deliverable ties to users → customers → revenue, never
  reach for its own sake.
- **Measurement first** — if there's no funnel data, the first act is to instrument it.
  Projections carry `[TBD — funnel data]` until then.
- **Draft-first, no live changes without sign-off** — we read public surfaces and build;
  nothing ships without the founder's ok.
- **Low-touch cadence** — ~2 calls + ~3 short messages/week, one weekly written report.
  The founder's scarcest resource is their attention; we remove overhead, never add it.
- **Never re-pitch what was declined** (e.g. the declined Second Brain) — keep only the
  one piece the marketing genuinely cannot work without, folded in at no extra cost.
- **Integrity rules carry into other clients** — no "pass-guarantee" shortcuts, AI is a
  tool never the authority, one shared source of truth for facts so nothing drifts.
- **Position by job, not by re-selling competence** — "I have 0 concern about your
  ability" = stop selling skill, sell the role + the revenue engine.

- [ ] Run Phase 0 audits against the new client's surfaces (reuse Bayan's audit shells).
- [ ] Write outreach email from **template — Phase 1** (own the delay, conversion-first,
      fee + acceptance point).
- [ ] Stand up the **single-link plan page** (clone `-v3.html` shell).
- [ ] Decide the fee ladder entry rung from their incumbent pricing.
- [ ] On "go", send the **fee + task-list email** (template — Phase 3) and start Week 1.
- [ ] Log the new client here as a cross-reference so each case sharpens the play.

*One rule unifies it all: if a task can't be tied to a funnel stage and a number, it's the
wrong task — reconcile before doing it.*
