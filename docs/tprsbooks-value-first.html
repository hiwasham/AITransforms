How this was made

We ran a live discovery audit of tprsbooks.com: six real teacher searches checked against where you rank, three classroom questions put to Claude, a homepage markup inspection, and a speed measurement from your actual mobile traffic. That audit became eight scoped work items. Each was drafted, reviewed against your own brand voice, and set aside for a human at TPRS Books to approve. The week was build time, not planning time — this is the same system we run for other clients, which is why the volume took days.

The eight things we built

Every card below is the same shape: the gap we measured, what we drafted to close it, and the honest expected effect. Figures are measured from your site; projected numbers are labelled as projections, never promised.

1 · Homepage discovery package

Drafted · held for review
Gap
Your homepage has no title tag, no meta description, no Open Graph tags, and no structured data — and it carries 64 H1 headings, so crawlers can't tell what the page is about. Shared in a Facebook group or staff email, the link arrives as a bare grey box.
Built
A page title and meta description, a single-H1 hierarchy, Organization JSON-LD, Open Graph tags for clean link previews, plus llms.txt and llms-full.txt drafts so AI tools can read the site properly.
Effect
Site & content health, measured at 59 today, projected to 100 once applied.
SEO · move 1

2 · Spanish learning-books page

Drafted · held for review
Gap
“spanish language learning books” is searched about 2,900 times a month. tprsbooks.com does not appear in Google's top 100 for it.
Built
A dedicated page with title, meta description, H1 and copy targeting that search, in your own teacher-focused voice, with verified internal links to the matching readers.
Effect
Targets a 2,900/mo gap. A ranking is never guaranteed — the page is the shot, not a promise.

7 · Safe WordPress speed set

Drafted · held for review
Gap
Real mobile visitors wait about 4.2 seconds (75th percentile) before your main content appears. A teacher on a school connection comparing two suppliers doesn't wait four seconds.
Built
A change set of the safe wins only: roughly 450ms recoverable from unused CSS, and about 150ms each from CSS and JS minification. No redesign, no risk to the live theme.
Effect
Measured recoverable time, not a guess. Held for review before anything is applied.
