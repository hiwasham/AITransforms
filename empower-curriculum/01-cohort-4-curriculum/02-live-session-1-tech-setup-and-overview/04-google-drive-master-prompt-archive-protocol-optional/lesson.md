# Google Drive Master Prompt Archive Protocol (optional)

> Curriculum › Section 2: Live Session 1 : Tech Setup & Overview › Lesson 4

[Open on Circle](https://community.empowerlabs.ai/c/curriculum-f7e760/sections/886669/lessons/3357914)

## Content

## WHY THIS MATTERS

**Problem**: Claude Projects are only accessible with Claude Pro/Team subscriptions and can't easily be shared with team members who don't use Claude. While we recommend using a Claude Team subscription, we offer this option protocol to archive your Master Prompt in Google Drive for additional flexibility.

**Solution**: Create a simple Google Drive archive that:

- ✅ Works with any Google account (free or paid)
- ✅ Can be shared with unlimited team members
- ✅ Creates a permanent backup of all work
- ✅ No complex folder structures to maintain
- ✅ Clear naming makes everything searchable

---

## ONE-TIME SETUP (10 minutes)

### Create Your Folder Structure

1. **Create Main Folder**
  - Open Google Drive ([drive.google.com](http://drive.google.com/))
  - Click "New" → "New folder"
  - Name it: EMPOWER - [Your Company Name]
2. **Create 12 Session Folders.** Inside your main folder, create these folders:

```
   00 - Master Documents
   01 - Tech Setup & Overview
   02 - The Invisible Structure of Business
   03 - The EMPOWER Operating System
   04 - Expansion Capability
   05 - Marketing & Brand Equity
   06 - Profitability Metrics
   07 - Offering Excellence
   08 - Workforce & Leadership
   09 - Execution Systems
   10 - Robust Market Position
   11 - Sustainable AI Integration
```

1. **Share with Team (Optional)**
  - Right-click main EMPOWER folder → "Share"
  - Add team members' emails
  - Set permissions (Editor/Commenter/Viewer)

**Done! Now you're ready to archive.**

## NAMING CONVENTIONS

These are suggested prefixes to keep files organized within each folder:

### Document Type Prefixes

```
ASSESS_ - Assessment results
SOP_ - Standard Operating Procedures
GUIDE_ - How-to guides and checklists
VISUAL_ - Diagrams and flowcharts (HTML files)
ANALYSIS_ - Data analysis and reports
PROFILE_ - Business profiles and summaries
MASTER_ - Master Prompt versions
NOTES_ - Working notes and brainstorming
SPRINT_ - Implementation sprint plans
RACI_ - RACI matrices
```

### Version Control

Consider adding version numbers and dates:

- v1, v2, v3 for major updates
- YYYY-MM-DD for date stamps
- CURRENT tag for active version

**Examples:**

- SOP_Order-Fulfillment_v1_2025-10-22
- MASTER_Prompt_v3_CURRENT_2025-11-15
- ASSESS_Market-to-Lead_2025-10-22

## ARCHIVING WORKFLOW

### Simple 5-Minute Routine (After Each Session)

**After completing any session:**

1. **Identify artifacts created**
  - Look for documents, assessments, SOPs, and diagrams in Claude
  - Artifacts appear in the chat or in Project Knowledge (left sidebar)
2. **For each artifact:**
  - **Option A: Select and copy text directly**
  - Click inside the artifact to open it
  - Select all text (Ctrl+A or Cmd+A)
  - Copy (Ctrl+C or Cmd+C)
  - **Option B: Use copy button (if available)**
  - Look for a copy icon in the artifact header
  - Click to copy the entire artifact to the clipboard
3. **For text documents:**
  - Open Google Drive → Navigate to the session folder
  - Click "New" → "Google Docs"
  - Apply naming convention (see table above)
  - Paste content (Ctrl+V or Cmd+V) → Save
4. **For HTML diagrams:**
  - Click inside the diagram artifact
  - Right-click → "Save as" or use the browser's save function
  - Save as .html file to your computer
  - Upload to Google Drive the session folder
  - Apply naming convention with .html extension
5. **Update Master Documents (if needed):**
  - Copy current Master Prompt to 00 - Master Documents/
  - Copy any consolidated profiles or roadmaps
  - Keep only the latest "CURRENT" versions

**That's it! 5 minutes and you're done.**
