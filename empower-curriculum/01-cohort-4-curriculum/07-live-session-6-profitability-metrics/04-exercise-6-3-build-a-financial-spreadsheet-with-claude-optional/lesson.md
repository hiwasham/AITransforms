# Exercise 6.3: Build a Financial Spreadsheet with Claude (Optional)

> Curriculum › Section 7: Live Session 6: Profitability Metrics › Lesson 4

[Open on Circle](https://community.empowerlabs.ai/c/curriculum-f7e760/sections/901140/lessons/3421040)

## Content

### Purpose

Apply the two-step method to create a useful financial tool with Claude. This demonstrates the spec-first approach that prevents rework.

### The Two-Step Method

**Phase 1: Create the Spec**  
What you do: Define purpose, inputs, outputs, calculations, and formatting  
Why it matters: Ensures Claude builds exactly what you need

**Phase 2: Build the Sheet**  
What you do: Claude creates the spreadsheet from your spec  
Why it matters: No rework, no misunderstandings  
Instructions

### **Step 1: Choose a Spreadsheet to Build**

Based on your assessment in Exercise 6.1, pick ONE spreadsheet that would:

- Address a gap in your Books to Insights level
- Help you influence one of the 7 Financial Levers
- Support the metrics you track

### **Suggested options**

- **Cash Flow Forecast** - 13-week rolling forecast with AR/AP aging
- **Variance Analysis** - Budget vs actual with automatic flags
- **DSO/DPO Tracker** - Days outstanding with aging buckets
- **Break-Even Calculator** - Unit economics with sensitivity analysis
- **KPI Dashboard** - Automated metrics from source data
- **Pricing Model** - Cost-plus and value-based with margin targets
- Or choose your own based on what would have the biggest impact.

### **Step 2: Run the Spec Creation Prompt**

In a NEW Claude chat (or continue in your Exercise 6.1 chat), copy and paste this prompt:

→ **[Access the Prompt](https://docs.google.com/document/d/130JlqKzDo6eQLeXve0yE9v54CSILlt1ahdnf4GSJp28/edit?tab=t.ct0e546l7io5#heading=h.5bapoqy2rq7w)**

Time to complete: 25-35 minutes

---

### **Step 3: Answer Claude's Questions**

Be specific about your actual situation. Reference your Finance Assessment when relevant.

### **Step 4: Approve the Spec**

Review Claude's specification document. Make sure it captures everything you need. Request changes if needed.

### **Step 5: Build the Spreadsheet**

Once the spec is approved, tell Claude:

The spec is approved. Please build the spreadsheet now. Create it in a format I can download and use immediately.

### **Step 6: Test and Iterate**

Download the spreadsheet and test it with real data. If adjustments are needed, describe them to Claude and have it update the file.

### **Step 7: Document Your Learning**

Save the completed spreadsheet and note:

- What problem this solves
- Which financial levers it helps you influence
