## Summary

### Resolving Project Diagram Discrepancies

Hayden and Nancy discussed the process of adding sale-to-delivery and delivery-to-success elements to Stage 3, with Hayden planning to provide specific instructions in the next session. Beni raised a question about discrepancies in visual diagrams between different project chats, which Hayden helped resolve by explaining how to properly copy and reference artifacts in the project. Hayden advised Beni to use Opus for queries when reaching the limit on Sonnet, and suggested asking the AI to display a visual diagram for the customer journey of the consulting product.

### Stage 3 and Claude Integration

Hayden explained Stage 3, a tool for managing master prompts and processes after the cohort, including version control and batch operations. Don expressed gratitude for the progress made since joining the first cohort and mentioned using Claude to replace FileMaker, which significantly reduced costs. Kristina inquired about using Claude Code for their real estate operating system, which manages lease contracts and financials, and Hayden suggested exploring custom ERP solutions using Airtable with Claude after completing the delivery to success.

### Custom CRM with Airtable Savings

Hayden shared his experience building a custom CRM system using Airtable, which saved his company $30,000 annually by replacing Salesforce. He recommended using industry-standard software like QuickBooks for finance, while building the ERP portion with Airtable due to its flexibility and API integrations. Jonas expressed interest in this approach, noting that while it was previously seen as overkill, it is now a viable option. Nancy discussed her experience organizing prompts and documents, using a master prompt with context from previous work to efficiently manage her artifacts.

### Workflow Automation and Process Planning

Hayden explained the plan for the next five sessions, emphasizing the importance of creating visual diagrams and core processes for each workflow. He suggested focusing on one specific process to implement during the cohort while building out blueprints in Stage 3 or Claude later. Hayden also described a workflow using Zapier and a note-taking tool, which automates tasks like call scoring, CRM updates, and follow-ups, significantly improving feedback loops and efficiency. Don inquired about accessing the related videos, and Hayden directed him to the Alumni Circle forum and Forte Labs' YouTube channel.

### Mermaid Diagrams and Troubleshooting

Hayden demonstrated how to create and use Mermaid diagrams for visualizing workflows, explaining that Claude can now generate them and recommending ExcalaDraw as a tool for editing. Beni encountered issues with a previous chat session where the HTML file wasn't recognized, and Hayden helped troubleshoot by suggesting Beni open the file in a text editor to inspect the content. When they discovered the file was missing the "contracting" section, Hayden advised creating a new chat with the same prompt to try again.

### Chat Artifacts and Process Evolution

Hayden and Beni discussed technical issues with chat artifacts and how to transfer chat content between different platforms or LLMs. Hayden provided guidance on copying artifacts and creating new chat sessions, offering to investigate further issues if needed. Jonas raised concerns about working with assumptions in business processes and sought advice on validating his work with the team. Hayden advised creating initial process versions for team review, emphasizing that current processes are not final and future versions will likely incorporate more technology. They discussed how roles and responsibilities may evolve as processes are automated, with Hayden noting that AI will likely transform many traditional roles in the coming years.

### Improving Assessment Prompt Tailoring

The group discussed issues with assessment prompts and their impact on the quality of results, particularly for Beni who found the second assessment less comprehensive than the first. Hayden suggested adding a specific instruction to tailor questions to Beni's med tech industry and recommended creating separate chats for different services to avoid confusion and improve results. They also addressed technical issues with a chat session that had caused problems, with Hayden advising Beni to try uploading artifacts to a different chat if similar issues arise in the future.
