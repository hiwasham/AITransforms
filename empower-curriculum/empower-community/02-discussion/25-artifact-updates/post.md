# Artifact updates

> Discussion › Post 25 › by Beni Hirt › 2026-02-02

[Open on Circle](https://community.empowerlabs.ai/c/discussion-b92449/artefact-updates)

## Content

I wonder how I can keep artifacts up to date.

Due to the naming restriction when copying it directly into the project, I used copy & paste as text. Now, I need to update my resources because I forgot an important point. Do I need to replace the text file by deleting the existing one and creating a new one?

Could it be automatically updated when copying an artifact directly into the project?

- **Jonas** · 2026-02-02 · 2 👍
  I always download mine as mark down and save it locally.  
  If I need to change something I usually open a new chat (or the existing) depending on what I need or want, copy my existing one and prompt it so I can create the necessary changes in a conversation mode. Then it creates a new artifact which I replace the old one with. Not sure if this is the most efficient one but it works for me, as I A) want to make sure I have all the information stored (locally) and not somewhere lost in a conversation with AI and B) I can directly work with my latest artifact (even if I’d switch the AI model for example). Hope it helps.

- **Josh Cordes** · 2026-02-02 · 2 👍
  There are a variety of ways to do this, but you can do what you suggested by replacing the new file by deleting the existing one and adding the updated one.  However you may not need to create a new chat, it would be better to go into the same chat with the finalized artifact & just make the revision there.  You will be able to see all your artifacts from the past & thats why its good to date them.  Hope that helps.
