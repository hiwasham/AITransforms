# Kortex makes notebooklm more useful

> Discussion › Post 38 › by Don Bury › 2026-02-25

[Open on Circle](https://community.empowerlabs.ai/c/discussion-b92449/kortex-makes-notebooklm-more-useful)

## Content

I’m not affiliated.  FYI I recently installed Kortex extension in chrome and same day bought a lifetime license for $39.  It merges notebooks, imports claude chats,  facilitates pushing podcasts and much more.  This fixes a lot of organization shortcomings I’ve been waiting for NotebookLM to fix. [https://kortex-notebooklm.com/docs/](https://kortex-notebooklm.com/docs/)

  - **Don Bury** · 2026-02-25
    @mention First open a notebooklm file, then click the Kortex button in the browser, then click manage notebooks.  From there you can do many things, including list all sources from all notebooks, merge notebooks, filter sources.  Thus it is now possible to set up a new notebook with sources you select to focus the new notebook.  I have about 250 notebooks, that don’t talk to each other.  (I’d like to be able to query my entire notebooklm account, but I would hit limits combining all into one.) For one client I had developed about 8 notebooks, and creating a new one with all the sources just took a few minutes.  Creating podcast rss channels has a lot of potential too.  Then saving prompts looks like a potent tool.  Anyway, I find this tool makes notebooklm more valuable.  Hope this helps.  Importing claude chats is handy too.
