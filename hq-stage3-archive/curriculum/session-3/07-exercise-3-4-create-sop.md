# Exercise 3.4: Create the Level 1 & 2 SOP (Sale to Delivery)

## Purpose

To create a map of the core process "Sale to Delivery" (Level 1) as well as blueprints for each functional area within the process (Level 2).

---

## The 4-Level Documentation Framework

| Level | Name            | What It Is                                                           | Owner                   |
| ----- | --------------- | -------------------------------------------------------------------- | ----------------------- |
| **1** | Core Process    | High-level overview of how a major function works across departments | Directors/Executives    |
| **2** | Blueprint       | Full breakdown of a repeatable business function (the map)           | Managers/Directors      |
| **3** | Guide           | Step-by-step instructions for a specific role to execute             | Senior ICs/Managers     |
| **4** | Forms/Templates | Actual tools, scripts, and documents used in the work                | Individual Contributors |

In this exercise, you will create **Level 1** and **Level 2** documentation only. Levels 3 and 4 are covered in separate exercises.

---

## Instructions

> **Tip:** Before starting, open your [Sale to Delivery process](/business-processes/15/cores) in a new browser window so you can reference it while working with the Sessions Coach side by side.

1. Click the **"Start Exercise"** button below to open the Sessions Coach

2. The AI will explain the 4-Level Documentation Framework and clarify that this exercise focuses on Level 1 & 2

3. The AI will check your Knowledge Base for product/service information:
    - If found: It will suggest documenting that product/service
    - If not found: It will ask what you'd like to document

4. **Level 1: Core Process Documentation**

    The AI will create two documents for you:
    - **Process Flow Diagram**: A visual table showing phases, steps, and RACI assignments
    - **Written Overview**: Detailed documentation with objective, steps, tools, checklist, and metrics

    After completing Level 1, you'll have two options:
    - **Option A**: Convert the Process Flow into a Core structure in the system (creates Core, Blueprints, and Activities)
    - **Option B**: Save the Written Overview to your Knowledge Documents

5. **Level 2: Blueprint SOPs**

    For each phase/blueprint in your Core, the AI will generate a detailed Blueprint SOP including objective, scope, triggers, step-by-step flow, RACI assignments, and success criteria.

    After each Blueprint SOP, you can save it directly to that Blueprint entity in the system.

6. Review your completed documentation and make any adjustments as needed

[Start Exercise](#magic-button)

**Time to complete:** 20-30 minutes

---

## What You'll Create

By the end of this exercise, you'll have:

**Level 1 - Core Process:**

- A **Process Flow Diagram** showing phases, steps, and RACI assignments (in markdown table format)
- A **Written Overview** with objective, process overview, detailed steps, required tools, checklist, key metrics, and common issues
- Optionally: A **Core structure** in the system with Blueprints and Activities

**Level 2 - Blueprint SOPs:**

- **Blueprint SOP documents** for each phase of your process
- Each blueprint includes: header info, objective, scope, triggers, key inputs, step-by-step flow, success criteria, RACI matrix, common pitfalls, and core values integration
- SOPs saved directly to Blueprint entities in the system
