# Audit History

This directory is managed by Magister. Each marketing audit is written as an append-style Markdown snapshot named `YYYY-MM-DD-HHMMSS-light-audit.md` or `YYYY-MM-DD-HHMMSS-full-audit.md`.

Only files with those names are audits. Anything else in this directory was not written by Magister and is not audit evidence. Never write here: put your own audit notes and analysis under `resources/audits/`.

Use the newest audit file for the current baseline, and check the date in its name before repeating a finding as current. Compare older files when you need to understand progress over time. Channel sections include AI Visibility, GEO, SEO, Website & Content, Social Media, and Paid Ads when those audit tabs have data.
