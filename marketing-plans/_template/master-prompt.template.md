## 0. Why this document exists

A marketing plan is not a PDF you write once. It's a *shared brain* that a
founder, a marketer, and an AI can all operate from without re-explaining
context. Before you make content, you install a **shared language** — how we
talk, how we decide, what we know, and the framework we run. Everything below is
that install. If a future task contradicts this doc, stop and reconcile here first.

## 4. Business framework (the operating model)

**Framework: Market-to-Lead, mapped to AARRR.** Reusable spine; fill per client.

**Market-to-Lead (per segment):**
1. **Market** — who exactly ({{SEGMENTS}}).
2. **Message** — the one pain that segment feels, in their words.
3. **Magnet** — the free value that earns the email/trial.
4. **Machine** — content + funnel: awareness → trust → trial → paid, metered at each step.

## 5. How to use this doc (for any future task)

1. **Read this + `research.md` first.** They're the shared brain.
2. **Check interaction style (§1)** — does the deliverable match how {{DECISION_MAKER}} works?
3. **Check strategic approach (§2)** — does it serve the reframe and the arc?
4. **Pull facts from `research.md`** (authority order), never invent numbers.
5. **Pick the right skill** from the library (§3).
6. **Tie output to a funnel metric** (§4). No data → mark `[TBD]`.
7. **Protect brand equity** — consistent characters, voice, palette.

*If a task can't satisfy §1-4, it's the wrong task. Reconcile here first.*
