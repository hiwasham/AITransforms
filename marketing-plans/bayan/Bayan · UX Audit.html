01 — money bleeding today

Two silent defects. Verified live in the product.

These aren't opinions — they're reproduced on the running site. The first blocks every ad-dollar signal; the second makes paying learners see "no history" the moment they open the dashboard.

verified live

CSP blocks every GA4 and Google Ads beacon

The connect-src policy allows www.google-analytics.com — but GA4 sends to region1.analytics.google.com, which is not whitelisted. The browser refuses every request. Ad spend is being optimized against zero conversion signal.

Reproduced in DevTools console on bayan.edu.om · blocked endpoints observed
verified live

Two authenticated queries return HTTP 400

The dashboard reports "no sessions / 0 questions today" to a user who has answered questions — because quiz_sessions dies silently. The OSCE page can't load its station list for the same reason.

Reproduced by walking the logged-in learner dashboard · silent failure, no crash

◆ No lift numbers will be promised

A researcher's pitch needs evidence, not fabricated lifts.

01 · Benchmark context

Published UX-to-conversion studies establish that these classes of fix — routing, prompt placement, first-value onboarding — tend to matter. They are external context, not this product's numbers.

02 · Real leaks

The CSP and 400-defect findings are live-verified. We can point at money leaving the system this second, with screenshots. This is what we don't need to model.

03 · Step 1 is measurement

The project's first deliverable is instrumentation, not a prediction. "We don't have funnel data yet — so we start by creating it." Identical framing to the marketing plan's Week 1.
