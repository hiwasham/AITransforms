# screenshots — captured views

Full-page captures of the logged-in bayan.edu.om learner app, read-only. Desktop
+ mobile widths so the section docs can reference the rendered UI, not just the
API shape. Test-account PII visible in-frame (greeting name, institution) is
low-resolution UI chrome, not a data payload; the identifying API fields it
mirrors are git-ignored and redacted in the docs.
