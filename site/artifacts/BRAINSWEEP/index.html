Brainsweep

Golden Rule: Capture, Don't Act. This file is a cognitive prosthesis for distractions, shiny objects, V2 ideas, and open loops that are not on the Critical Path of the current BUILD-PACKET.md.

Raw Input Area

Dump ideas here immediately. Do not evaluate, research, organize, or act on them during the current Intermediate Packet.

  • [ ] [Shiny object, tool, course, feature idea, question, or unrelated task]
  • [ ] [Another captured thought]

Shiny Object Triage

Use this only when the urge to switch tasks is strong.

  1. Ask: Is this on the Critical Path of the current BUILD-PACKET.md?
  2. If no, label it as extraneous load and capture it in Raw Input.
  3. If the idea still feels urgent, allow one 15-minute exploratory sprint.
  4. If value is not obvious after 15 minutes, stop and return it to this file for Friday Freeze.
  5. If boredom is driving the urge, downscope the current packet instead of switching projects.

Friday Freeze

At the end of the week, sort the Raw Input Area into PARA so this file does not become an endless pile of shoulds.

Captured Item Energy Level Destination (PARA) Action
[Item Name] [High / Medium / Low] [[Project X]] Task
[Research Topic] [Medium] [[Resources/AI]] Reference
[Low-utility idea] [Low] Archive Delete or archive

Rituals

  • [ ] During Work: Keep this file available in a side pane and dump distractions immediately.
  • [ ] Friday 4:00 PM: Review the raw list, sort items into PARA, and move useful items to their destination notes.
  • [ ] Zero-Load Rule: After sorting, clear the Raw Input Area so next week starts with a clean mind.

Why This Works

  • Quarantines distractions without denying that the idea exists.
  • Reduces memory fatigue by storing open loops in a trusted external system.
  • Protects Return-on-Attention by preventing new tools, courses, and AI models from mining attention during execution.
  • Uses energy management so future tasks can be matched to high, medium, or low-energy windows.
  • Turns fleeting distractions into durable assets during Friday Freeze.
