# Email Script Library

Use this skill when Hiwa asks to write, rewrite, analyze, or template emails/outreach based on his saved scripts or examples.

## Core workflow
1. Identify the email type: cold outreach, follow-up, intro, thank-you, ask-for-advice, collaboration, investor/business, apology, reply, or reactivation.
2. Read `references/index.md` to choose the closest pattern family.
3. If examples exist for that family, read only the relevant example file under `references/examples/`.
4. Draft in Hiwa's voice: human, concise, specific, respectful, non-corporate, and not over-polished.
5. Preserve true facts only. Never invent relationship, achievements, quotes, urgency, or promises.
6. Offer 1 strong version by default; add subject lines or alternate versions only when useful.

## Safety and boundaries
- Draft and critique freely.
- Do not send emails, access inboxes, save sensitive contacts, or run campaigns without explicit approval.
- Use public, legitimate research only when recipient context is needed.
- Prefer official/professional contact channels.

## Resources
- `references/index.md` — pattern map and when to use each template family.
- `references/ramit-50-scripts-map.md` — transformed index/principles from the user-provided Ramit Sethi 50 scripts PDF.
- `references/style-guide.md` — Hiwa voice rules extracted from scripts.
- `references/examples/` — curated examples, grouped by pattern.
- `assets/templates/` — reusable fill-in templates.

## If scripts have not been imported yet
Ask Hiwa to upload/paste the scripts, then classify them into the reference structure before drafting from this skill.
