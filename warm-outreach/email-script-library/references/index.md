# Email Script Library Index

Status: Ramit Sethi 50 scripts PDF imported as a transformed pattern map. See `ramit-50-scripts-map.md`.

## Pattern families

1. Cold outreach to respected people / gurus
2. Founder or business collaboration
3. Ask for advice or feedback
4. Warm follow-up after no reply
5. Thank-you / appreciation without asking
6. Intro request
7. Meeting request / call ask
8. Investor or acquisition/business contact
9. Reply to an interested person
10. Reconnect / revive old contact

## Import process for new scripts

For each script, capture:
- Pattern family
- Intended recipient
- Goal / ask
- Emotional angle
- Strong lines worth reusing
- Weak/AI/corporate lines to avoid
- Reusable template shape

Store sanitized examples in `references/examples/<family>.md` and generic templates in `assets/templates/<family>.md`.
