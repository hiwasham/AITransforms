I'm a subscriber on your email list. Your VIP Summer Sale email landed in
my inbox this week, and as someone who does conversion-focused design
work, the hero banner caught my attention — so I rebuilt it. Redesigned
version attached, no strings. Use it, A/B test it, or ignore it.

Why I thought it was worth redesigning:

  1. The offer is split across the email. The banner says "Up to 50% Off
     + Extra 25%," but the parts that actually drive action — VIP-only,
     £40 spend threshold, code INSIDER25, ends tonight — live in the
     body copy. Readers scan; they don't assemble. The redesign makes
     the banner self-contained, so the full value proposition lands in
     the first ~3 seconds.

  2. The discount code isn't in the banner. INSIDER25 is the single most
     actionable element of the email, and the customer has to go find
     it. The redesign puts "USE CODE INSIDER25" front and center, which
     should help redemption directly.

  3. The stacking is easy to misread. "Extra 25%" leaves people
     wondering whether it's already included. The redesign shows
     50% × 25% visually, so the stacked saving is obvious — that's
     perceived value you're currently leaving on the table.

  4. Urgency and exclusivity are textual, not visual. "Hurry" and "Email
     VIPs only" work harder as symbols: the redesign uses a stopwatch +
     "Ends at Midnight" for time pressure and a VIP badge for
     exclusivity, and adds a SHOP NOW button directly in the hero so
     there's an action path before any scrolling.

One practical note: the original banner image is a 2.4 MB PNG. That's
heavy for an email hero — it slows first paint on mobile and some
clients will lag or skip it. The attached version is a fraction of the
size.

The honest caveat: none of this is proven until it's A/B tested against
your current creative. But every change maps to a known friction point —
cognitive load, memory friction on the code, unclear stacking, weak
visual urgency — so it's a cheap test with a plausible upside on CTR,
code redemption, and average order value (the £40 threshold is now
visible before the click).
