Tools

Surfaces it can check, permissions it respects

Surface monitoring

Watches bayan.edu.om, bayanai.tech, medad.om, the App Store, Google Play, and every brochure PDF you share. Add a new surface — no extra charge.

See Surfaces watched

Read-only, public surfaces only

The brain reads public surfaces. It does not log in, it does not edit, it does not see learner data.

No access to learner accounts, exam results, internal dashboards, CRM data, or financial data.

Permission levels

Dr. Abdullah: approve facts. Nasim: add/remove surfaces, publish. Booth staff: ask questions. Hiwa: build and maintain. Each role has an off switch.

Circuit breakers

If the brain finds more than 20 conflicts in one check, it stops and sends an alert. Prevents false positives from flooding the report.

Example: if bayan.edu.om goes down and returns error pages, the brain reports "surface unreachable, check skipped" — not "every fact is missing."

Activity log

Every check is logged: when it ran, which surfaces it checked, how many conflicts it found, who received the report.

The log shows the last 52 weeks. Export it as CSV if you need it for audit.

Off switch for every surface

Nasim controls which surfaces the brain watches. Add a new product page — tell the brain to check it. Remove a deprecated brochure — the brain stops checking next week.
