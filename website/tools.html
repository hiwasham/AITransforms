Circuit breakers

If the brain finds more than 20 conflicts in one check, it stops and sends an alert. This prevents false positives from flooding the report.

Example: if bayan.edu.om goes down and returns error pages, the brain doesn't report "every fact is missing" — it reports "surface unreachable, check skipped."

Activity log

The log shows the last 52 weeks. Export it as CSV if you need it for audit.
